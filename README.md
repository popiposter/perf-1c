# perf-1c

Локальный инструментарий диагностики производительности **1С + Microsoft SQL Server**.
Связываем замедление пользователя с измерениями Windows, SQL Server и 1С;
отделяем факты от гипотез и проверяем эффект изменений.

**Версия: 0.1.1-pilot.** Добавлены запуск из публичного GitHub и поддержка PowerShell 7
на Windows. Проверки на реальном Windows/SQL Server ещё не выполнены.
Это диагностический комплект, не автоматический оптимизатор.

## Одна команда в PowerShell 7

Откройте **PowerShell 7 x64 (`pwsh.exe`) на Windows**. Первый запуск на одну минуту:

```powershell
& { $s = Join-Path $env:TEMP ("perf-1c-" + [guid]::NewGuid() + ".ps1"); Invoke-WebRequest 'https://raw.githubusercontent.com/popiposter/perf-1c/main/Start-OneCPerf.ps1' -OutFile $s -ErrorAction Stop; & $s -Minutes 1 }
```

Будут запрошены экземпляр SQL и имя SQL-базы. Enter для экземпляра означает `.`
(локальный экземпляр по умолчанию), Enter для базы — пропустить детали конкретной базы.
Используется Windows-аутентификация текущего пользователя. Полные требования и права:
[README_RU.md](README_RU.md).

Для среза во время проблемы замените в конце `-Minutes 1` на `-Minutes 10 -IncludeMaintenance`.
Без вопросов, с известными параметрами, в конце команды используйте, например:

```powershell
& $s -SqlInstance 'SQL_HOST\INSTANCE' -Database 'DB_NAME' -Minutes 10 -IncludeMaintenance -NonInteractive
```

Это фрагмент **внутри блока исходной команды**, вместо `& $s -Minutes 1`;
`SQL_HOST\INSTANCE` и `DB_NAME` — примеры, не параметры вашего сервера.
На отдельном сервере 1С используйте `& $s -SkipSql -Role onec -Minutes 10`.

Код скачивается в новый подкаталог `$env:LOCALAPPDATA\perf-1c\downloads`,
а замеры — в `$env:LOCALAPPDATA\perf-1c\captures`. Путь к ZIP выводится после сбора.
Прежние результаты не перезаписываются. Git, Python и модуль SqlServer на сервере не нужны.
Сборщик выполняется в текущем PS7; локальный запуск в Windows PowerShell 5.1 также сохранён.

Загрузчик разрешает `main` в конкретный commit SHA, скачивает комплект этой версии,
записывает источник и хеш архива, затем запускает сборщик. Для фиксации версии используйте
`-Ref <40-символьный SHA>` и тот же SHA вместо `main` в URL загрузчика.
`-DownloadOnly` позволяет сначала скачать и проверить код без сбора данных.
Это доверие к коду вашего репозитория по HTTPS, а не независимая проверка подписи.
Нужен доступ к raw.githubusercontent.com, api.github.com и codeload.github.com.

**Нет** автоматического изменения ExecutionPolicy, отключения проверки сертификатов,
установки служб, повышения привилегий или отправки результатов.
При корпоративном запрете скриптов используйте согласованный порядок их запуска.

## Структура

- `Start-OneCPerf.ps1` — загрузка и запуск из PS7.
- `Collect-OneCPerf.ps1` и `sql/` — ограниченный сбор; `analyze.py` — автономный отчёт.
- `tests/` — целевые проверки; `docs/case-template.md` — карточка инцидента.
- `docs/roadmap.md`, `docs/sources.md`, `AGENTS.md` — развитие, источники и правила.
- `SHA256SUMS.txt` — контрольные суммы исходного импорта 0.1, не изменённой версии.

## Проверки

```powershell
python -m unittest discover -s tests -v
pwsh -NoProfile -File .\tests\Test-PowerShell.ps1
```

Python проверяет анализатор. Тест PowerShell проверяет синтаксис и логику загрузчика
с подменённой сетью, а на Windows — создание SQL-провайдера **без соединения**.
В среде подготовки 0.1.1 PowerShell отсутствует: PS-тест добавлен, но не выполнен.
Первым реальным шагом остаётся минутный срез и проверка `coverage.html`.
CI автоматически не включается.

## Диагностические данные

**Репозиторий публичный; замеры — нет.** Не публикуйте реальные архивы, журналы,
SQL-планы, резервные копии, пароли или сведения заказчика в Git и Issues.
`.gitignore` не заменяет проверку содержимого. Перед передачей ZIP проверьте его:
он не обезличен и не зашифрован. Автоматической выгрузки данных нет.

Метрики Windows относятся к узлу запуска. Для разных серверов SQL и 1С нужны отдельные
сборы с одним `CaseId`. Сбор → проверка полноты → гипотезы → точечная диагностика →
согласованное изменение → сравнение до/после.
